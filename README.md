# Emoji Food & Habit Calendar

A lightweight, mobile-first monthly calendar web app to log foods, treats, and daily habits using compact emojis—with custom global meanings that update across every past and future month.

## Features
- **Box-Grid Monthly Calendar:** Each date cell neatly displays up to **15 mini emojis** per day (`🍛`, `🧇`, `🍦`, etc.).
- **Tap-to-Inspect Day Popup:** Tap any date box to view a full breakdown (`[Emoji] — [Custom Meaning]`) of everything logged that day, add new items in one tap, or remove entries.
- **Global Emoji Meaning Editor:** Assign custom labels to any emoji (even non-literal ones like `🐉` for *Extra Spicy Feast*). Updating a meaning automatically updates it across all dates and months.
- **100% Private Local Storage:** All logs and emoji meanings are saved directly in your phone's browser storage (`localStorage`).

## How to Add to Your Phone's Home Screen
1. Open the live GitHub Pages link (`https://<your-username>.github.io/food-calendar/`) in **Google Chrome** (Android) or **Safari** (iPhone).
2. **Android (Chrome):** Tap the **three-dot menu (`⋮`)** → **Add to Home screen** (or **Install app**).
3. **iPhone (Safari):** Tap the **Share** icon → **Add to Home Screen**.
